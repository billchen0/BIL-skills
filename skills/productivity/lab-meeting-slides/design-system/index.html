Central design system / v1

Lab meeting slides

A shared visual language for calm, legible research storytelling. The Slides tab is the canonical layout gallery: every specimen is a live 16:9 HTML stage using the same tokens and components as generated decks.

Thesis

Quiet structure for complex work

Use generous whitespace, a single dominant idea, and a horizontal trajectory motif to help a research group orient quickly.

Contract

One source of truth

Tokens, components, format hooks, the gallery, and the example deck are local and dependency-free. Agents read this workspace before creating new slides.

Medium

Fixed-stage HTML

Slides are 1920 × 1080 stages scaled uniformly to the viewport. The outer workspace may reflow; the slide composition does not.
